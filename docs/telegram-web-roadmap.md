# EdgeChat → Telegram Web 功能对齐全景路线图

本项目目标是在现有的 Cloudflare Pages + D1 + 轮询无常驻长连接的架构下，将 EdgeChat 的聊天体验全面对齐 Telegram Web（web.telegram.org，以 WebK / WebA 为参考系）。

根据技术可行性与交互依赖关系，将全量功能拆分为六个交付批次：

---

## 批次概览

| 批次 | 主题 | 包含功能 | 状态 |
|---|---|---|---|
| **Batch 1** | **核心消息交互** | 表情回应 (Reactions)、消息编辑、真实 HTTP 删除、消息转发、多选操作、右键/长按菜单统一 | **进行中（本次交付）** |
| **Batch 2** | **搜索与定位** | 会话内消息搜索、全局跨会话搜索、消息直链与深层跳转 | 计划中 |
| **Batch 3** | **会话组织** | 会话文件夹/分组、置顶会话、归档、服务端草稿同步、标记未读 | 计划中 |
| **Batch 4** | **表情、贴纸与媒体** | 完整 Emoji 选择器、贴纸包与 GIF 支持、相册/媒体组、全屏媒体查看器 (Lightbox) | 计划中 |
| **Batch 5** | **群组与频道进阶** | 广播频道、入群申请与审批、细粒度管理员权限、封禁与禁言名单、邀请链接生命周期 | 计划中 |
| **Batch 6** | **个性化与多端** | 自定义壁纸与配色、定时消息、收藏夹 (Saved Messages)、聊天记录导出、活跃设备与会话踢出 | 计划中 |

---

## 各批次详细规范

### Batch 1: 核心消息交互（本次）

- **表情回应 (Reactions)**：
  - 数据模型：`message_reactions (message_id, user_id, emoji, created_at)`，单人对同一条消息单 emoji 幂等。
  - API：`POST /api/v1/rooms/:kind/:id/messages/:messageId/reactions`（切换），`GET /api/v1/rooms/:kind/:id/messages/:messageId/reactions`。
  - 实时性：通过 `message_events` 触发 `updated` 事件，利用现有的游标轮询自然同步，零侵入下沉到所有客户端。
  - 前端呈现：气泡下方展示已聚合的 Emoji 气泡（含数量、我是否点过、点击即可快捷附和/取消），气泡悬停/右键提供常用快捷 Reaction 栏（👍 ❤️ 🔥 😂 👏 🎉）。
- **消息编辑 (Edit Message)**：
  - 权限：仅限本人发送的本地消息，在时效内可编辑。
  - 后端：`PATCH /api/v1/rooms/:kind/:id/messages/:messageId`，消息正文重新走 AES-256-GCM 服务端信封加密，更新 `edited_at` 字段并向 `message_events` 插入 `updated` 事件。
  - 前端：右键菜单「编辑」，输入栏原位变为「编辑模式」（带取消与保存按钮，支持 Esc 取消），气泡时间戳旁展示「已编辑」标记。
- **消息删除 (Delete Message)**：
  - 解决历史遗留缺陷：此前 Web 端的 `deleteMessage` 尝试通过空 WebSocket 发送指令，现统一走 `DELETE /api/v1/rooms/:kind/:id/messages/:messageId` HTTP 接口。
  - 权限校验：本人消息或群主/管理员可删，软删除后触发 `message_events` 的 `deleted` 事件。
- **消息转发 (Forward Message)**：
  - 数据模型：消息增加 `forward_from_sender_name`, `forward_from_channel_name` 投影元数据。
  - 前端交互：右键选择「转发」，弹出目标会话选择对话框（支持群聊与私聊快速搜索），选定后自动携带「转发自 ...」的 Telegram Web 经典引用顶栏发出。
- **多选模式 (Multi-Select Mode)**：
  - 进入方式：右键菜单点击「选择」，或长按触发选择。气泡左侧/右侧弹出勾选框，顶栏切换为「已选 N 项」操作栏。
  - 批量操作：批量转发、批量删除（本人有权限项）。
- **上下文菜单 (Context Menu)**：
  - 整合回复、表情回应、复制内容、编辑、置顶/取消置顶、转发、选择、删除于一体的 Telegram 风格悬浮菜单。

### Batch 2: 搜索与定位

- **会话内搜索**：支持在当前会话按关键字检索历史消息，支持命中高亮、上下文跳转与结果计数。
- **全局搜索**：侧边栏顶部搜索框扩展为全局模式，同时聚合会话、联系人与历史消息正文。
- **消息永久链接**：支持复制 `/#/chat/:kind/:id?msg=:messageId` 链接，点击自动激活房间、滚入可视区并闪烁高亮。

### Batch 3: 会话组织

- **会话文件夹**：顶部支持标签页切换（全部、未读、群组、私信、自定义文件夹）。
- **置顶会话**：会话在侧边栏支持置顶，数据存入 `user_pinned_rooms` 表。
- **会话归档**：不常查看的会话可收进「归档」折叠列表。
- **草稿云同步**：未发出的文本定期写入服务端 `room_drafts` 表，换设备或刷新后自动恢复。

### Batch 4: 表情、贴纸与媒体

- **Emoji 选择器**：集成带分类、搜索与最近使用的纯前端 Emoji Picker。
- **贴纸包与 GIF**：通过外部图床与 GIF API（如 Tenor/Giphy 无代理镜像）支持发送贴纸与动图。
- **相册/媒体组**：单条消息支持附加最多 10 张图片，以网格相册形态紧凑排版。
- **媒体查看器**：点击图片/视频进入全屏查看器，支持平移、滚轮缩放、下载与前后翻页。

### Batch 5: 群组与频道进阶

- **广播频道**：新增 `channel` 类型的会话，仅管理员可发言，订阅者仅读，支持阅读量计数。
- **进群审批**：私有群组可开启「需管理员批准」，用户申请后进入审核列表。
- **细粒度管理权限**：针对管理员分配「更改群信息」、「删除消息」、「封禁用户」、「添加管理员」等独立权限。
- **邀请链接生命周期**：群内支持生成带有效期、最大使用人数、带名称备注的临时邀请链接。

### Batch 6: 个性化与多端

- **聊天壁纸与气泡配色**：提供 Telegram 经典纯色/暗纹背景与气泡配色方案。
- **定时消息**：设置未来时间点，由惰性触发器或队列在到期后发送。
- **收藏夹 (Saved Messages)**：个人专属的云端收藏本，支持任意消息转发保存与个人速记。
- **会话管理**：在「设置 → 活跃设备」里查看所有登录的会话，支持一键踢出其他设备。
